# RED SMS · PHP

Понадобятся PHP CLI и расширение `curl`. Скопируйте шаблон конфигурации из корня репозитория.

```sh
cp config.php.dist config.php
```

В `config.php` укажите логин и API-ключ. Для отправки также укажите свой номер в международном формате и зарегистрированное имя отправителя. Файл `config.php` исключён из Git.

| Метод API | Команда из корня репозитория |
|---|---|
| `GET /api/client/info` — информация об аккаунте | `php samples/clientInfoSample.php` |
| `POST /api/message` — отправка одного платного SMS | `php samples/smsSendsample.php` |
| `GET /api/message/{uuid}` — запрос статуса | `php samples/messageStatusSample.php UUID` |

После отправки возьмите UUID из `items[0].uuid`. Передайте его в запрос статуса и прочитайте `item.status`: значение `delivered` подтверждает доставку.

HTTP 200 подтверждает создание хотя бы одного сообщения. При частичном принятии скрипт показывает UUID принятых сообщений и ошибки по другим номерам. Доставку подтверждает статус `delivered`. При `created`, `moderation` и `progress` можно позже повторить запрос статуса.

При HTTP 401 проверьте данные для подписи и список разрешённых IP. При HTTP 420 проверьте баланс. При тайм-ауте отправки повторный POST может создать дубликат.

Дополнительные примеры в `samples` показывают получение списка имён отправителей и создание SMS-рассылки.

[Справочник HTTP API](https://docs.redsms.ru/http/api/) · [Статусы сообщений](https://docs.redsms.ru/http/api/message/)
